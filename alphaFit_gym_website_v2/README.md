# Gym / Fitness Website

A responsive multi-page gym and fitness website built using **HTML, CSS, and JavaScript**, with **Google Sheets integration** to store contact form submissions.

## Project Overview

This project is designed as a frontend website for a gym/fitness business. It includes multiple sections such as Home, About, Programs, Nutrition, Membership, and Contact.  
The website also includes a contact/book-a-session form that sends user data to **Google Sheets** using **Google Apps Script**.

This project was created for a frontend subject and follows a simple, clean, and practical structure.

---

## Features

- Responsive multi-page website
- Clean gym/fitness theme
- Navigation bar for easy page switching
- Programs section
- Membership section
- Nutrition section
- FAQ / interactive UI elements
- Contact / booking form
- Google Sheets integration for form data storage
- No Node.js, no backend server, and no email system required

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Unsplash images
